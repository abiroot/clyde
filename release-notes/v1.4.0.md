### Model choice per session
- `/model` in a session now changes only that session. Two sessions in the same folder can run different models; before, a pick moved every session on the provider.
- In a folder pinned to Kimi or Refuseless, `/model` now lists all of the provider's models. Before, it showed the same model four times.
- Use "s" in `/model` to switch for the current session without changing the default for new ones.
- The model menu on a provider's card sets the default for sessions that haven't picked their own.

### Choose when long sessions compact
- New **Compact** menu on Kimi and Refuseless cards: at 256K (default), 512K or 1M tokens. Every request resends the whole conversation, so a bigger size costs more per turn on pay-per-token providers.
- `/model` now shows where each model compacts (for example "1M context · compacts at 256K"). Before, it showed only the context size.

### Add account
- The Add account window uses a side menu grouped into Claude accounts and other models, so every option is visible. The "Kimi…" tab is now separate Kimi and Refuseless entries.
- Esc or a click outside closes it.

### Updates
- Update notices now have a "What's new" link with the release notes.
